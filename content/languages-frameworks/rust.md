## Pourquoi Rust ?

Rust élimine les bugs de gestion mémoire (buffer overflow, use-after-free) sans garbage collector. Il cible les cas d'usage où Go ne suffit pas : traitement de données à très haute fréquence, compilation WebAssembly.

## Expérimentation en cours

Nous évaluons Rust pour notre pipeline de transformation de données. La courbe d'apprentissage est significative mais les résultats de performance sont remarquables.

## Recommandation

**En évaluation** — réservé aux équipes expérimentées et aux contextes où la performance est critique.
