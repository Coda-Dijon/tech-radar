## Pourquoi GitHub Actions ?

GitHub Actions est parfaitement intégré au workflow GitHub. La marketplace propose des milliers d'actions réutilisables. La facturation à la minute est compétitive pour la plupart des projets.

## Retour d'expérience

Tous nos pipelines CI/CD sont sur GitHub Actions. Les workflows YAML sont versionnés avec le code, ce qui simplifie la revue et le debugging.

## Recommandation

**Standard pour tous les projets.** Utiliser des actions réutilisables en interne pour standardiser les workflows.
