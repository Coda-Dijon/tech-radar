## Contexte

Jenkins a été pendant longtemps la référence CI/CD. Sa flexibilité via les plugins était un atout. Aujourd'hui, la complexité de maintenance (JVM, plugins, configuration XML) est un frein.

## Situation actuelle

Jenkins tourne encore sur quelques projets legacy. La migration vers GitHub Actions est planifiée pour Q2.

## Recommandation

**Ne pas adopter** pour de nouveaux projets. Planifier la migration des instances existantes.
